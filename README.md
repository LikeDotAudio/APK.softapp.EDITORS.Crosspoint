# EDITORS.Crosspoint — Crosspoint Matrix Routing Editor

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery.

Crosspoint Matrix Routing Editor: visual N×M routing grid for audio and video routers; manage source-to-destination crosspoints, lock ties, disconnects, salvo presets, and level tallies.

| | |
|---|---|
| **Opens** | the OS shell (Design → Routing & Matrix), or `index.html` standalone |
| **Build** | none — plain web files; `npm test` |
| **Ships** | baked into WEB.Frontend-Assets (`up-stack.sh WEB.Frontend-Assets`), served at `:8080/Softapps/EDITORS/EDITORS.Crosspoint/` |
